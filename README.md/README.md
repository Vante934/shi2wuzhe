## 📖 项目简介

> "识食物者为俊杰"

**识食物者** 是一个高灵感、智能的美食搭配与菜谱推荐生鲜社区。在这里，好好吃饭，寻找随机美味，建立属于你自己的厨房小天地。

不同于传统菜谱 App 的被动查询，识食物者将 **AI 智能推荐、美食社区、生鲜灵感** 融为一体，让每一次下厨都充满惊喜。无论是想尝试新口味、寻找食材搭配灵感，还是和美食爱好者交流分享，识食物者都能满足你。

## 🚀 快速开始

### 环境要求

- Node.js >= 20.20.2
- npm >= 9

### 本地开发

```bash
# 克隆项目
git clone https://github.com/Vante934/shi2wuzhe.git
cd shi2wuzhe

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的 Gemini API Key

# 启动开发服务器
npm run dev
```

启动后访问 `http://localhost:3000` 即可查看效果。

### 构建部署

```bash
# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

本项目已配置 Vercel 自动部署，推送到 main 分支即可自动部署。

## 🔧 环境变量

复制 `.env.example` 为 `.env` 并配置以下变量：

```env
# Google Gemini API Key
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# API 基础地址
VITE_API_BASE_URL=/api
```
